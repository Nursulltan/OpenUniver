# Open Univer — неофициальный клиент univer.kaznu.kz для Android

Расписание, оценки, журнал, сессия, УМКД, дистанционные курсы, e-услуги, задолженности и калькулятор баллов КазНУ в одном приложении. Интерфейс на казахском, русском и английском.

**Приложение неофициальное и не связано с КазНУ им. аль-Фараби.**

## Приватность

- У приложения нет своих серверов, аналитики, рекламы и трекеров.
- Запросы идут с телефона напрямую на `https://univer.kaznu.kz` и `https://univerapi.kaznu.kz`, больше никуда.
- Логин и пароль хранятся только на устройстве, в Android Keystore (`@aparajita/capacitor-secure-storage`).
- Скачанные файлы лежат во внутренней памяти приложения.
- Код защиты хранится только в виде PBKDF2-отпечатка; отпечаток пальца и лицо проверяет сама система Android.

## Как устроено

В версии 0.9.0 профиль, расписание, список УМКД и экзамены используют мобильный API КазНУ с резервным HTML-путём. Общий GPA, текущие оценки, подписи заданий и максимумы сохраняют HTML-источник: проверенный API предоставляет неполные или отличающиеся данные. Подробности — в корневом `README.md`, раздел «Какие данные откуда берутся».

| Папка / файл | Что там |
|---|---|
| `../kaznu-test/univer.mjs` | вход на сайт и разбор HTML-страниц (общий для тестового сервера и приложения) |
| `../kaznu-test/mobile-api.mjs` | отдельная API-сессия, кэш запросов и преобразование JSON |
| `../kaznu-test/index.html`, `i18n.js` | интерфейс и переводы |
| `src/backend.js` | «сервер» внутри приложения: маршруты `/api/...`, нативный HTTP, Keystore, файлы |
| `build-web.mjs` | собирает `www/` (esbuild) |
| `android/` | Android-проект Capacitor |

## Сборка

Нужны Node.js 22+, JDK 21 и Android SDK (platform 36).

```bash
npm install
node build-web.mjs
npx cap sync android
cd android && ./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
